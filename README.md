# Java Weight Converter

A simple Java console program that converts weight between pounds and kilograms.

## Features

- Convert pounds to kilograms
- Convert kilograms to pounds
- Uses Scanner for user input
- Formats output to two decimal places
- Handles invalid menu choices

## What I Practiced

- Java variables
- Scanner input
- if/else statements
- arithmetic operations
- printf formatting

## Example

Welcome to the weight conversion program!  
1: Convert pounds to kilograms  
2: Convert kilograms to pounds  
Please enter your choice: 1  
Please enter the weight in pounds: 150  
The new weight in kilograms is: 68.04
